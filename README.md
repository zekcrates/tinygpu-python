## Pipeline

```
FETCH → DECODE → REQUEST → WAIT → EXECUTE → UPDATE → FETCH ...
```


## ISA

| Opcode | Instruction | Operation |
|--------|-------------|-----------|
| 0000 | NOP | do nothing |
| 0001 | BRnzp | branch if N/Z/P flags |
| 0010 | CMP | compare R[rs] vs R[rt] |
| 0011 | ADD | R[rd] = R[rs] + R[rt] |
| 0100 | SUB | R[rd] = R[rs] - R[rt] |
| 0101 | MUL | R[rd] = R[rs] * R[rt] |
| 0110 | DIV | R[rd] = R[rs] / R[rt] |
| 0111 | LDR | R[rd] = data_mem[R[rs]] |
| 1000 | STR | data_mem[R[rs]] = R[rt] |
| 1001 | CONST | R[rd] = immediate |
| 1111 | RET | end thread |

## Registers (per thread)

| Register | Name | Description |
|----------|------|-------------|
| R0-R12 | general | read/write |
| R13 | blockIdx | read-only |
| R14 | blockDim | read-only|
| R15 | threadIdx | read-only |
